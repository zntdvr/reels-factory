# База знаний для сценариев

Зачем: без опоры ИИ пишет «среднее по интернету» — те же зацепки и формулировки,
что у всех. Сценарий становится своим, когда стоит на материале, которого нет у
других: наши истории, наши цифры, наша позиция.

## Что где лежит

| Путь | Что там |
|---|---|
| `voice.md` | голос компании: кто мы, для кого, как говорим, во что верим, запретные штампы. Читается перед каждым сценарием |
| `writing-reference.md` | ориентир для подачи сценариев по предоставленному Telegram-архиву; приёмы, адаптация для речи и границы заимствования |
| `feedback.md` | замечания заказчика к готовым роликам. Читается перед каждой сборкой и правкой; новое замечание дописывается сразу |
| `topics-excluded.md` | темы, которые уже сняты или не нравятся человеку. Читается при каждом подборе тем; новая тема дописывается сразу |
| `raw/ID.txt` | полный текст материала — расшифровка, статья, конспект. Руками не правится |
| `notes/ID.md` | выжимка материала. Именно по ней ищутся опоры для сценария |

Добавляет материал `npm run kb -- --add <файл или ссылка> [--kind own] [--title "…"]`.
Видео и аудио расшифровываются локально тем же распознаванием, что и озвучка.
Статью по ссылке, PDF или Word ИИ читает сам, сохраняет текст в `.txt` во
временную папку вне проекта и добавляет этот файл с `--source <ссылка>`.
Просмотрщик страниц отдаёт только пересказ, поэтому статью скачивать `curl` и
доставать текст основного блока страницы.

`--kind own` — **своё**: эфиры, выступления, наши ролики и посты, кейсы, переписки
с клиентами, голосовые заметки. Без пометки материал считается **внешним**: книга,
чужая статья, чужое видео.

## Как писать выжимку

Заметку заводит скрипт со `status: draft`. ИИ читает `raw/ID.txt` целиком и
заполняет разделы, затем ставит `status: ready` и теги.

- **О чём** — две-три строки.
- **Мысли** — тезисы своими словами, по одному на строку. Только неочевидное:
  то, что «все и так знают», не записывать.
- **Истории и случаи** — самое ценное. Кто, что случилось, чем кончилось,
  конкретные детали. Детали и делают историю своей; без них она превращается в
  штамп.
- **Цифры и факты** — с источником и, для расшифровок, с меткой времени `[12:40]`.
- **Цитаты дословно** — живые фразы, которые можно произнести в ролике как есть.
  Для своих материалов это ещё и образец нашего голоса.
- **Наша позиция** — для внешних материалов обязательно: в чём мы согласны, где
  спорим, что видим иначе из своей практики. Без позиции ролик выйдет пересказом
  чужой книги. Не знаешь позиции — так и написать: «позиция не ясна, спросить», и
  спросить человека.
- **Идеи роликов** — 1–3 зацепки, которые здесь просятся. Черновые.

Теги — короткие, по-русски, через запятую: `tags: [аутсорс, бухгалтерия, сбой]`.

Пометка `used` ведётся скриптом: после утверждения сценария
`npm run kb -- --used ID --project ПРОЕКТ` для каждой взятой опоры. Одну и ту же
историю в соседних роликах подписчик замечает сразу.

## Порядок наполнения

Начинать со своего — 10–20 материалов дают больше, чем сотня книг. Внешнее
добавлять как сырьё для споров и аргументов.
