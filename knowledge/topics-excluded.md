# Темы, которые не предлагать

Читается скиллом `topics` перед каждым подбором тем. Темы из этого списка не
попадают в таблицу ни в каком потоке: ни из базы, ни из новостей, ни из вечных.

Файл лежит в проекте, поэтому переезжает вместе с папкой на любой компьютер.
Пополняется сразу, как только человек сказал «это уже снимали» или «эта тема не
нравится» — одной строкой в нужный раздел, с датой и причиной.

## Не нравится

Пока пусто. Формат строки: `тема — дата — почему не нравится`. Причина нужна,
чтобы отсеивать и похожие темы, а не только дословно эту.

## Как применять

- Совпадение по смыслу считается совпадением: «простой офиса» и «сколько стоит
  час без компьютеров» — одна тема.
- Новый угол у уже снятой темы сам по себе не снимает запрет. Предлагать такой
  угол можно только если человек прямо разрешил вернуться к теме.
