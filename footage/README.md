# Банк видеоотрывков

Свои отрывки для видеовставок: виды города, офис, производство, руки за
работой. Система ищет здесь первой, раньше Pexels и YouTube: права на свои
кадры есть всегда, а поиск по банку мгновенный.

    npm run footage                                         что лежит в банке
    npm run footage -- --add ~/Видео/office.mov --title "офис, общий план"
    npm run footage -- --add https://… --title "…" --license "…"
    npm run footage -- --find "hands typing on a laptop"    найти кусок
    npm run footage -- --remove office-obschiy-plan

При добавлении отрывок переводится в общий формат, а кадры размечаются
моделью CLIP. Поэтому ручные подписи «что где» не нужны: поиск идёт по смыслу
кадра.

Сами видео в git не попадают: в репозитории лежит только этот файл.
`clips/` — отрывки, `frames/` — разметка, `bank.json` — список.
