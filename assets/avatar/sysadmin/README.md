# Аватар системного администратора

## Основной аватар: `sysadmin.blend`

Готовый к анимации персонаж: модель Quaternius со скелетом, тёмный лонгслив и серые брюки в цветах стиля, очки, гарнитура с микрофоном и синий бейдж на шнурке. Аксессуары привязаны к костям `Head` и `Torso` и двигаются вместе с любой анимацией. Превью: [в полный рост](preview_body.jpg), [крупно](preview_head.jpg), [в ходьбе](preview_walk.jpg).

- Скелет — объект `Sysadmin_Rig`, тело — `Sysadmin_Body`, аксессуары — коллекция `Sysadmin_Props`.
- Анимации (24 кадра/с): `Man_Idle`, `Man_Walk`, `Man_Run`, `Man_Clapping`, `Man_Sitting`, `Man_Standing`, `Man_Jump`, `Man_RunningJump`, `Man_Punch`, `Man_Roll`, `Man_SwordSlash`, `Man_Death`. Нужная выбирается у `Sysadmin_Rig` в Action Editor.
- Лицо смотрит в −Y, рост модели около 4,8 единицы.
- Пересборка из исходника: `tools/blender/blender -b assets/avatar/sysadmin/Male_LongSleeve_Quaternius.blend --python assets/avatar/sysadmin/make_sysadmin.py` (с `-- --preview` заново рисует превью).

## Исходная модель с ригом и анимациями

`Male_LongSleeve_Quaternius.blend` — оригинальная модель **Male LongSleeve** из [Animated Men Pack от Quaternius](https://quaternius.com/packs/animatedmen.html). Автор описывает набор как четыре модели с анимациями в форматах Blender, FBX и OBJ. Файл скачан из [папки автора](https://drive.google.com/drive/folders/1L_FjbsDeWVN7a7V5jAt2cMCgLeOESvVF); заголовок `BLENDER-v279` проверен. Откройте его в Blender через **File → Open**. Это основа для системного администратора: очки, гарнитуру и фирменные цвета потребуется добавить в Blender.

На странице набора указана CC0, а [текущая страница лицензии автора](https://quaternius.com/license.html) разрешает использовать модели в коммерческих видео и запрещает распространять сами исходники как отдельные ассеты. Если будете публиковать эту папку или пакет моделей, проверьте условия у автора.

## Созданная для проекта модель

`sysadmin_avatar.glb` — самостоятельная 3D-модель для Blender. Она сделана в стиле проекта: тёмный костюм, тёплый белый и один синий акцент `#245CFF`. На персонаже очки, гарнитура с микрофоном и рабочий бейдж. Геометрия и материалы находятся внутри одного файла; внешние текстуры не нужны.

## Импорт в Blender

1. **File → Import → glTF 2.0 (.glb/.gltf)** → выберите `sysadmin_avatar.glb`.
2. В Outliner найдите `ROOT | move whole avatar`. Это общий узел персонажа. Повороты головы, корпуса, рук и ног делайте через соответствующие узлы `Head`, `Torso`, `Upper arm`, `Forearm`, `Leg` и `Foot`.
3. В **NLA Editor** найдите импортированные дорожки `01 Idle | 4s loop`, `02 Wave | 2.4s` и `03 Typing | 2s loop` у анимированных узлов. Включайте нужные дорожки вместе для всего персонажа; для повтора задайте `Repeat` у NLA strip. При 30 кадрах/с длительность клипов составляет 120, 72 и 60 кадров соответственно.
4. Для вертикального ролика поставьте камеру перед персонажем (его лицо смотрит вдоль локальной оси **+Z** исходного GLB), соотношение кадра 9:16. Используйте прозрачный фон рендера, если будете накладывать персонажа поверх сцен.

Модель собрана из отдельных деталей с родительскими узлами. Это удобно для поворотов и стилизованной анимации; для плавной деформации кожи и одежды потребуется отдельный скелетный риг в Blender. Мимика пока ограничена геометрией лица.

Файл можно пересобрать без Blender: `python3 assets/avatar/sysadmin/build.py` из корня проекта.
